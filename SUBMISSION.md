# Submission checklist

The live official submission form and latest organizer guidance take precedence.

## Global requirements
- [ ] Every participant is registered and listed on the project/team page. Official 2026 site says teams have at most six members.
- [ ] Select an official 2026 challenge and address it directly.
- [ ] For Global Awards eligibility, integrate at least one NASA data source from that challenge's Resources and cite it.
- [ ] List all data, resources and tools used, including code, text, imagery and AI tools; get permission for copyrighted materials.
- [ ] Submit the official project page by **Nov 15, 2026, 23:59 local time** per the [2026 event hub](https://www.spaceappschallenge.org/2026/).
- [ ] Read [2026 terms](https://www.spaceappschallenge.org/legal/) and the latest [submission guide](https://www.spaceappschallenge.org/resources/); follow live form fields and age/privacy rules.

## Final checks
- [ ] Working end-to-end demo; fallback for network failure.
- [ ] Demo/pitch accurately describe what works; no invented results.
- [ ] Project title, summary, challenge response, description, demo and code/project links match live form.
- [ ] Sources, tools and AI use are disclosed as required; link permissions work for outsiders.
- [ ] Remove secrets, personal data and unlicensed material; verify team, links and submitted status; save confirmation.
