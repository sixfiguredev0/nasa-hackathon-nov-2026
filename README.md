# Junior Astronaut Mission Trainer

NASA Space Apps Challenge 2026 entry: a browser-playable game for kids ages 7 to 12 who run a lunar or Martian outpost and learn real mission trade-offs (power, life support, radiation shielding) grounded in NASA open data.

> Status: **pre-production**. Engine and art style are not decided yet. See [`docs/decisions/`](docs/decisions/).
